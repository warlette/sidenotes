SideNotes Privacy Policy

Effective Date: August 14, 2026

SideNotes is a Chrome extension for creating and organizing notes in Chrome's native side panel. This privacy policy explains what information SideNotes handles and how it is protected.

1. Information Handled by SideNotes

SideNotes handles only user-initiated data, including:

  • Notes, note titles, categories, tags, and pinned status created or edited by the user.
  • The title and URL of the active browser tab only when the user explicitly clicks Clip Page or Insert Page Link.
  • Website text that the user explicitly selects and sends to SideNotes via a right-click context menu command.
  • User preference settings (e.g., light/dark theme preference and active note selection).
  • JSON note files explicitly selected by the user for import.

2. How Information Is Used

Information processed by SideNotes is used strictly to provide the extension's note-taking, organization, search, import, export, and user-requested web-clipping features. No data is used for secondary purposes.

3. Local Storage & Zero Data Transmission

All notes, saved links, selections, and preferences are stored 100% locally in your Chrome browser profile using Chrome's secure chrome.storage.local API. SideNotes does not operate remote servers, does not transmit user notes, titles, or web clippings to external endpoints, and does not include any advertising or third-party analytics trackers.

4. Sharing and Selling

SideNotes does not sell, rent, or share user data with any third parties. It does not transfer data for advertising, marketing, profiling, or creditworthiness evaluations.

5. User Control and Data Deletion

You retain total control over your data. Notes can be modified or deleted directly within the extension UI at any time. Uninstalling the SideNotes extension automatically removes all locally stored data from your browser.

6. Chrome Web Store Limited Use Adherence

SideNotes' use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.
